## Матриця нефункціональних вимог (NFRs)

| Категорія | Ключові обмеження |
|---|---|
| Продуктивність | p95 ≤ 200 мс для операцій читання при 200 RPS; p95 ≤ 400 мс для резервування при 50 VU |
| Цілісність | 0 подвійних продажів при 500 одночасних спробах резервування одного квитка; TTL резерву 10 хв |
| Захист від ботів | Token Bucket: 20 запитів/с на IP (bucket 40), 5 резервувань/хв на обліковий запис; ≤ 4 квитки на подію |
| Безпека | OIDC (Authorization Code + PKCE), JWT RS256 зі строком дії 5 хв; TOTP для продавців; TLS 1.2+; ECDSA P-256 / SHA-256 |
| Інструментальний аудит | 0 вразливостей Critical/High (SonarQube, OWASP Dependency-Check, Trivy, OWASP ZAP); покриття ≥ 70 % |
| Надійність | Transactional Outbox (at-least-once); fallback на оптимістичне блокування PostgreSQL; RPO ≤ 24 год, RTO ≤ 1 год |
| Інфраструктура | Docker, `docker compose up`; Prometheus (15 с) + Grafana |
